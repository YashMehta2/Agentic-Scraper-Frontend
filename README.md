# Agentic Scraper - Frontend

A modern, responsive dashboard for the **Agentic Web Scraper**. This interface allows users to launch autonomous scraping tasks and monitor the agent's reasoning process in real-time.

## ✨ Features

- **Dynamic Dashboard**: Monitor multiple scraping jobs simultaneously.
- **Agent Reasoning Visualization**: See what the AI is "thinking" and the steps it takes (code execution, navigation, extraction).
- **Glassmorphism UI**: A premium, modern look with smooth transitions and animations.
- **Real-time Updates**: Automatic polling for job status and execution steps.
- **Responsive Design**: Works seamlessly across desktop and mobile devices.

## 🛠️ Tech Stack

- **Framework**: React.js
- **Styling**: Vanilla CSS (Modern Design System)
- **Icons**: Lucide React
- **Build Tool**: Vite

## ⚙️ Setup & Installation

1. **Navigate to the directory**:
   ```bash
   cd frontend
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Run the development server**:
   ```bash
   npm run dev
   ```

## 🖥️ Preview

The dashboard features:
- **Input Panel**: URL and Goal definition.
- **Execution History**: A list of all past and current jobs.
- **Step-by-Step Breakdown**: Detailed logs of every action the agent performs.
